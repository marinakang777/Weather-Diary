## Описание программы

Weather Diary — это графическое приложение для ведения дневника погоды. Оно позволяет:
- Добавлять записи с датой, температурой, описанием и отметкой об осадках.
- Просматривать все записи в удобной таблице.
- Фильтровать записи по дате или температуре (выше заданного значения).
- Сохранять данные в JSON-файл и загружать из него.
- Проверять корректность ввода данных.

Приложение разработано на Python с использованием библиотек `tkinter` (GUI) и `json` (хранение данных).

## Как запустить приложение

### Требования
- Python 3.6 или выше
- Стандартные библиотеки Python (tkinter, json, datetime, os) — они входят в поставку Python

### Установка и запуск

1. Скачайте файл `weather_diary.py`.
2. Откройте терминал/командную строку в папке с файлом.
3. Запустите приложение командой:
   ```bash
   python weather_diary.py
   В открывшемся окне вы можете добавлять записи, фильтровать их и сохранять.

Примеры использования
Пример 1: Добавление записи
В поле "Дата" введите 2026-05-20

В поле "Температура" введите 18.5

В поле "Описание" введите Солнечно, легкий ветер

Отметьте "Осадки", если нужно

Нажмите "Добавить запись"

Пример 2: Фильтрация
Чтобы показать все записи за 2026-05-20, введите эту дату в поле "Фильтр по дате" и нажмите "Применить фильтры".

Чтобы показать записи с температурой выше 15°C, введите 15 в поле "Температура выше" и нажмите "Применить фильтры".

Можно комбинировать оба фильтра одновременно.

Пример 3: Сохранение и загрузка
Нажмите "Сохранить в JSON" — данные сохранятся в файл weather_data.json в папке с программой.

При следующем запуске программа автоматически загрузит данные из этого файла (если он существует).

Кнопка "Загрузить из JSON" позволяет повторно загрузить данные вручную.

Тест корректности ввода
Попробуйте ввести дату в неверном формате (например, 20.05.2026) — программа покажет ошибку.

Попробуйте ввести буквы в поле температуры — получите ошибку.

Попробуйте оставить описание пустым — программа запросит заполнить его.
